# SAM-class cell-center detection spike (CLEAR-EC)

Goal: decide in one overnight run whether a segmentation model (Cellpose-SAM `cpsam`, plain SAM ViT-B) detects endothelial cell centers well enough that a Voronoi "center method" beats our ConvNeXt regressor (val: CD 6.4%, CV 11.8%, HEX 10.1%, mean 9.4%). Spike code: concise, no fallbacks, no abstractions beyond what two files need. Everything lives in this directory and runs from it.

## Hardware and environment
- 2x RTX A5000 24 GB, 16 cores, 92 GB RAM. Use `CUDA_VISIBLE_DEVICES` from the CLI; default GPU 0. Batch/tiling must fit 24 GB; images are 1296x972 grayscale uint8.
- Python env: `spike/sam/.venv` (torch 2.5 cu124, cellpose>=4 with `cpsam`, segment-anything). Do NOT touch `code/.venv` or anything under `code/`.
- Data (absolute paths, read-only):
  - images: `/home/visilant/CLEAR-EC/data/train_mha/<ID>.mha` (uint8 972x1296; read with SimpleITK) or the memmap `/home/visilant/CLEAR-EC/data/cache/images_u8.npy` shape (9000,972,1296) with `/home/visilant/CLEAR-EC/data/cache/index.csv` (idx, ID, slide_id) and splits `/home/visilant/CLEAR-EC/data/cache/splits.json` (train/val/test idx lists).
  - labels: `/home/visilant/CLEAR-EC/data/final_train_ids.csv` (ID, CD, CV, HEX).
  - overlays: `/home/visilant/CLEAR-EC/data/train_green/<ID>.tiff` (25 RGB 720x540 = 5/9 scale of the frame; green box + green dots = clicked cell centers). Pixel spacing 0.7716 um/px.
- Overlay split (fixed): train 19; val `0334-23`, `0587-23`; test `0324-23`, `0329-23`, `0471-23`, `0586-23`. Tune nothing on the 6 held-out.

## Files (interfaces are fixed so the two authors can work in parallel)
1. `overlays.py` — `load_overlays() -> dict[ID, dict(box=(x0,y0,x1,y1), dots=np.ndarray (N,2) x,y, split='train'|'val'|'test')]` in FULL-RES coordinates. Green = (G>100)&(G-R>50)&(G-B>50); box = rows/cols with >25% green; dots = green minus box lines, binary opening, distance transform + `peak_local_max(min_distance=3, threshold_abs=2)`, then scale by (1296/720, 972/540). Cache to `overlays.json`.
2. `readout.py` — `voronoi_metrics(points_xy, um_per_px=0.7716) -> dict(CD, CV, HEX, n_interior)`: Voronoi of the points; keep cells whose polygon is bounded and lies inside the convex hull of the points; CD = n_interior / sum(area_um2) * 1e6; CV = std/mean of interior areas; HEX = fraction of interior cells with exactly 6 Voronoi neighbours (region vertex count == 6). Also `match(det_xy, gt_xy, tol_px) -> dict(f1, precision, recall, count_ratio, med_loc_err)` using greedy nearest matching via cKDTree (each gt used once). Reference implementation of the Voronoi part that reproduced labels at CD MAPE 3.1% / HEX 6% on the dots is in `reference_readout.py` — reuse it.
3. `detect.py` — `detect(model_name, image_u8) -> np.ndarray (N,2) x,y centroids` for `model_name in {'cpsam','sam_vit_b'}`. cpsam: `cellpose.models.CellposeModel(gpu=True)` (cellpose 4 default = cpsam), `eval(img, diameter=None or ~25, flow_threshold, cellprob_threshold)` → masks → `regionprops` centroids; expose flow_threshold / cellprob_threshold / diameter as kwargs. sam_vit_b: `SamAutomaticMaskGenerator` on the RGB-replicated frame with points_per_side 64, pred_iou_thresh 0.7, stability 0.8, min_mask_region_area 100; centroids of masks with area between 150 and 2500 px. Download weights once into `weights/` (SAM ViT-B checkpoint URL is public; cpsam downloads itself). Keep a `time_s` measurement per image.
4. `eval_overlays.py` — CLI: `--model cpsam|sam_vit_b [--diameter D --flow F --cellprob C]`. For each of the 19 train overlays (and separately the 6 held-out, reported in their own block): run detect on the full frame, keep detections inside the convex hull of the GT dots (dilated by 0.5 cell diameters), compute match at tol = 0.5*median NN distance of the GT dots, and voronoi_metrics on (a) GT dots (oracle) and (b) the kept detections; compare to labels: per-metric APE, mean. Print a table per image and a summary (mean F1, count ratio, CD/CV/HEX MAPE for oracle vs detections) and save `results/<model>_<params>.csv`. Small grid allowed for cpsam: diameter in {None, 22, 28}, flow in {0.4, 0.6}, cellprob in {0.0, -1.0} — 12 runs x 19 images, minutes each.
5. `eval_val.py` — CLI: `--model cpsam --n 300 [--params ...]`. For the first N val images (split from splits.json): detect on the full frame; choose the analysis region like the annotator: slide a 540x408 window with stride 68 px, score each by band-pass energy (Gaussian sigma 2 minus sigma 6, mean absolute) and pick the argmax; keep detections in that window; take the largest contiguous cluster (Delaunay edges shorter than 1.6x median NN distance); voronoi_metrics → CD/CV/HEX. Report per-metric MAPE and log-space correlation vs labels, plus MAPE after a train-free global scale (median ratio) and save predictions to `results/val_<model>.csv`. Must be resumable (skip IDs already in the CSV).
6. `run_all.sh` — runs the overlay grid for cpsam, the single sam_vit_b overlay run, then `eval_val.py --model cpsam --n 300` with the best overlay params (pick by mean of CD/HEX MAPE on the 19 train overlays), logging to `logs/`. `watch_and_run.sh` — loops until no process matching `scripts/run_training.py` exists for 3 consecutive minutes, then runs `run_all.sh` with `CUDA_VISIBLE_DEVICES=1`.

## Gates (for the morning read)
- Detection: mean F1 >= 0.85 and |count_ratio - 1| <= 0.03 on the 19 train overlays, held-out 6 reported separately.
- Readout: CD MAPE <= 6% and HEX MAPE <= 9% from detections on the 19.
- Val: log-correlation with GT CD >= 0.85 on 300 val images (that is what ~6% CD needs); CV/HEX correlation reported.

## Style
- Plain functions, numpy/scipy, no classes unless needed, no try/except wrappers, no config systems. Each file < 150 lines. Progress via tqdm. Every script prints its summary table at the end.
